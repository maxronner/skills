# zk Reference

Agent-safe interaction with a `zk` notebook. Load this only when `zk` is available and relevant.

## Choose Notebook

Prefer an explicit notebook path from the user, local instructions, environment, or a wrapper. Pin commands to that path instead of relying on auto-discovery:

```bash
NB=/path/to/notebook
zk --notebook-dir "$NB" list --limit 1 --format '{{abs-path}}' --no-pager --quiet >/dev/null
```

If zk cannot locate/open the notebook, asks for a path, or warns that the configured notebook is missing, do not wander the filesystem looking for memory. Ask the user or use another configured interface.

Before reading/writing notes, read notebook-local rules if present (for example root `AGENTS.md`, `CLAUDE.md`, `README.md`, or relevant docs). Read `.zk/config.toml` or `zk config --list ...` only when templates, aliases, or creation behavior matter.

## Search

Use `list` first; do not read the whole notebook.

```bash
zk --notebook-dir "$NB" list \
  --match "$QUERY" \
  --match-strategy fts \
  --limit 20 \
  --format '{{title}}\t{{abs-path}}' \
  --no-pager \
  --quiet
```

Useful filters:

```bash
zk --notebook-dir "$NB" list "$SUBDIR" --format '{{title}}\t{{abs-path}}' --no-pager --quiet
zk --notebook-dir "$NB" list --tag "$TAG" --format '{{title}}\t{{abs-path}}' --no-pager --quiet
zk --notebook-dir "$NB" list --match "$QUERY" --match-strategy exact --format '{{title}}\t{{abs-path}}' --no-pager --quiet
zk --notebook-dir "$NB" list --modified-after 2026-01-01 --format '{{title}}\t{{abs-path}}' --no-pager --quiet
```

For structured results, use JSON and then read only selected `absPath` values:

```bash
zk --notebook-dir "$NB" list --match "$QUERY" --limit 20 --format json --no-pager --quiet
```

`--format json` includes `rawContent`; avoid it for broad searches if output volume matters.

## Links And Graphs

Use linkage filters when a note is known but context around it matters:

```bash
zk --notebook-dir "$NB" list --link-to "$PATH" --format '{{title}}\t{{abs-path}}' --no-pager --quiet
zk --notebook-dir "$NB" list --linked-by "$PATH" --format '{{title}}\t{{abs-path}}' --no-pager --quiet
zk --notebook-dir "$NB" list --related "$PATH" --format '{{title}}\t{{abs-path}}' --no-pager --quiet
zk --notebook-dir "$NB" graph --format json "$PATH" --quiet
```

## Read

Prefer the agent's file read tool on a selected `absPath`. Read a small number of notes; if they disagree with repo-local facts, prefer the repo.

## Write

Only write when the user explicitly asks.

1. Search for duplicates first.
2. Read notebook-local rules and `.zk/config.toml` if relevant.
3. Let `zk` allocate the path and template, then edit the created note.

```bash
path=$(zk --notebook-dir "$NB" -W "$NB" new --title "$TITLE" --print-path --no-input)
```

For a subdirectory:

```bash
path=$(zk --notebook-dir "$NB" -W "$NB" new "$SUBDIR" --title "$TITLE" --print-path --no-input)
```

Then use the agent's write/edit tool on `$path`, preserving front matter generated by the template unless local rules say otherwise.

Validate discoverability:

```bash
zk --notebook-dir "$NB" list "$path" --format '{{title}}\t{{abs-path}}' --no-pager --quiet
```

If search appears stale, `zk index` usually runs automatically; use this only when needed:

```bash
zk --notebook-dir "$NB" index --force
```

## Footguns

- `zk new` may treat the current working directory as the target location; use `-W "$NB"` to avoid "path is outside the notebook" errors.
- `zk edit` opens an editor; in agent sessions, prefer `zk list` + file read/write/edit tools.
- Do not process inbox/raw/import folders unless asked.
- Do not hand-create metadata, ids, or links when the notebook's templates/rules define them.
